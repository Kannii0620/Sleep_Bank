# 睡眠銀行

寝不足が、本当に借金になる銀行。

睡眠不足を「借金」として見せ、利息で増える“もったいなさ”で夜更かしを止めるWebアプリです。
「寝ろ」と叱るのではなく、損をしたくない気持ちで、寝る前に止めることをねらいます。

- ターゲット：夜更かしをやめたいのにやめられない学生（チーム自身が当事者）
- 世界観：銀行。窓口キャラがやさしく催促する（「そろそろ返してほしいな…」くらいの温度感）
- 開発チーム：学生4人（初心者中心）。ハッカソンで2週間かけて作る

## 仕組み（仮ルール）

数値はすべて仮で、テストしながら調整します。

| 項目 | ルール |
| --- | --- |
| 目標睡眠時間 | ユーザーが設定（例：7時間） |
| 換算レート | 1時間 = 100コイン |
| 目標より少なく寝た | 差分を借金として追加 |
| 目標より多く寝た | 差分をまず借金の返済に回す |
| 利息 | 借金残高に1日10%（強すぎる場合は単利や上限を検討） |
| 計算の順番 | 利息を足す → その夜の睡眠を反映 |

計算例（目標7時間）：

1. 5時間睡眠 → 2時間不足 → 借金200コイン
2. 翌日、利息10% → 220コイン
3. 8時間睡眠 → 1時間ぶん返済 → 120コイン

## 技術

フレームワークなしの HTML / CSS / JavaScript で作ります。サーバーは使いません。

| 用途 | 使うもの |
| --- | --- |
| 言語 | HTML / CSS / JavaScript |
| データ保存 | localStorage（ブラウザ内に保存） |
| 公開 | GitHub Pages |
| エディタ | VS Code + Live Server拡張 |

## ファイル構成

```
index.html   ホーム・おはよう・結果画面
morning.js   朝の画面の処理
night.html   おやすみ・夜の見込み・設定画面
night.js     夜の画面の処理
bank.js      換算・利息・ランク・保存・早送り（計算の中身）
style.css    見た目
images/      窓口キャラの絵
```

画面のファイルは `bank.js` の関数を呼んで表示するだけにします。

## bank.js の関数の約束

```js
goodnight()           // おやすみを記録
goodmorning()         // おはようを記録して結果を返す
getStatus()           // 借金・ランク・キャラの気分を返す
previewTonight(時刻)  // 今寝た場合の見込みを返す
```

## 動かし方

1. このリポジトリを clone する
2. VS Code で開き、`index.html` を Live Server で起動する
3. 公開版は GitHub Pages のURLで確認する（`main` ブランチに取り込まれると自動で更新される）
